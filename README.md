# SafeRoute BD
### Online Fraud and Cybercrime Reporting System

**Software Engineering Project | Project Planning | Requirements Engineering | Agile (Scrum)**

---

## 📌 Project Overview

SafeRoute BD is an academic Software Engineering project proposing an Online Fraud and Cybercrime Reporting System for Bangladesh. It aims to provide a centralized platform for reporting cybercrime, tracking incidents and accessing safety-related information.

This repository showcases the project's complete planning and documentation work, including:

- **Project Proposal:** Background, objectives, scope and proposed solution.
- **Software Requirements Specification (SRS):** Functional and non-functional requirements.
- **SDLC Model Selection:** Evaluation of development methodologies and selection of Agile (Scrum).
- **System Design:** ER, Use Case, Activity, Class and Sequence diagrams.
- **Software Testing:** 44 documented test cases covering major system modules.

The project emphasizes requirements analysis, system documentation, software development lifecycle planning and project management practices.

## 🎯 Project Objectives

- Establish a structured platform for online fraud and cybercrime reporting.
- Simplify incident submission and complaint management.
- Enable users to monitor submitted complaints and case progress.
- Improve public safety awareness through incident-based information.
- Propose route-safety analysis and emergency assistance features.
- Define system requirements, workflows and development strategies.

## 🚀 Proposed System Features

| Feature | Description |
|---|---|
| User Registration & Login | Account creation and authentication. |
| Incident Reporting | Submission of fraud, harassment and cybercrime complaints. |
| Case Tracking | Monitoring submitted reports and their progress. |
| Route Safety Analysis | Incident-based route-risk assessment. |
| Heatmap Visualization | Identification of areas with frequent reported incidents. |
| Emergency SOS | Emergency alert and assistance functionality. |
| Route Feedback | User feedback on route safety. |
| Data Security | Protection of personal and incident-related information. |

## 🧪 Software Testing & Test Cases

A structured test case document was prepared to cover the major functional modules of SafeRoute BD.

Testing coverage includes:

| Module | Testing Scope |
|---|---|

| User Registration | Valid registration, required fields and input validation. |
