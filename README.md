# SafeRoute BD
### Online Fraud and Cybercrime Reporting System

**Software Engineering Project | Project Planning | Requirements Analysis | Agile (Scrum)**

---

## 📌 Project Overview

SafeRoute BD is an academic Software Engineering project focused on designing a proposed Online Fraud and Cybercrime Reporting System for Bangladesh.

The project aims to establish a centralized platform where users can report online fraud, cybercrime, harassment and other safety-related incidents, track complaint progress and access relevant safety information.

The project focuses on software project planning, requirements engineering, system analysis, documentation, SDLC model selection and Agile project management.

## 🎯 Project Objectives

- Establish a structured platform for online fraud and cybercrime reporting.
- Simplify incident submission and complaint management.
- Enable users to monitor submitted complaints and case progress.
- Improve public safety awareness through incident-based information.
- Support route-safety analysis using reported and historical incidents.
- Propose emergency assistance and SOS functionality.
- Define requirements, system workflows and project development strategies.

## 🚀 Proposed System Features

| Feature | Description |
|---|---|
| User Registration | Account creation and identity verification. |
| Incident Reporting | Submission of fraud, harassment and cybercrime complaints. |
| Case Tracking | Monitoring submitted complaints and their progress. |
| Route Safety Analysis | Incident-based route-risk assessment. |
| Heatmap Visualization | Identification of areas with frequent reported incidents. |
| Emergency SOS | Emergency alert functionality. |
| Route Feedback | User feedback on route safety. |
| Data Security | Protection of personal and incident-related information. |
